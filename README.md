# 120 Years of Olympic History: Athletes and Results

## Project Overview

This project performs exploratory data analysis and visualization on the Kaggle dataset **120 Years of Olympic History: Athletes and Results**, covering the modern Olympic Games from Athens 1896 to Rio 2016.

## Dataset

**Source:** [120 Years of Olympic History: Athletes and Results — Kaggle](https://www.kaggle.com/datasets/heesoo37/120-years-of-olympic-history-athletes-and-results)

The dataset contains two files:

* `athlete_events.csv`: 271,116 rows and 15 columns, with one row per athlete-event record.
* `noc_regions.csv`: Contains National Olympic Committee (NOC) codes and corresponding region information.

## Project Objectives

* Analyze Olympic participation trends over time.
* Compare male and female participation.
* Explore medal distribution by country or region and sport.
* Study athlete age, height, and weight patterns.
* Compare participation in Summer and Winter Olympics.
* Create clear visualizations and document the findings.

## Tools and Technologies

* **Python:** Main programming language.
* **Pandas:** Data cleaning and analysis.
* **NumPy:** Numerical calculations.
* **Matplotlib:** Creating graphs and charts.
* **Seaborn:** Statistical data visualization.
* **Google Colab / Jupyter Notebook:** Writing and executing Python code.
* **Git and GitHub:** Version control and project documentation.

## Proposed Visualizations

1. Olympic participation by year.
2. Male vs. female participation over time.
3. Top countries or regions by medal count.
4. Medal distribution by sport.
5. Athlete age distribution.
6. Athlete age by medal status.
7. Height vs. weight scatter plot.
8. Summer vs. Winter Olympic participation.
9. Top athletes by medal count.

## Expected Outcomes

The project aims to identify long-term Olympic participation trends, changes in female representation, countries and sports with high medal counts, and patterns in athlete demographics. The findings will be based on the results obtained from data analysis and visualization.

## Methodology

1. Download the dataset from Kaggle.
2. Load the CSV files using Pandas.
3. Inspect the dataset and identify missing values and duplicate records.
4. Clean and preprocess the data.
5. Merge the datasets where required.
6. Perform exploratory data analysis.
7. Generate visualizations using Matplotlib and Seaborn.
8. Interpret the results and document the findings.

## Conclusion

This project will use Python-based data analysis and visualization to explore 120 years of Olympic history. It will provide insights into athlete participation, medal performance, sports, and demographic patterns. The completed analysis and documentation will be published on GitHub.
